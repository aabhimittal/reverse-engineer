# Curated resources

**Books**: *Practical Binary Analysis* (Andriesse); *Practical Malware Analysis* (Sikorski, Honig);
*Reversing: Secrets of Reverse Engineering* (Eilam); *The Ghidra Book* (Eagle, Nance);
*Hacking: The Art of Exploitation* (Erickson).

**Tools**: Ghidra, IDA Free, Binary Ninja, radare2/rizin + Cutter, x64dbg, gdb + pwndbg/GEF, Frida,
YARA/YARA-X, capa, FLOSS, binwalk, unblob, BinDiff, Diaphora, jadx, apktool, mitmproxy, Wireshark, tree-sitter.

**Practice**: crackmes.one, pwn.college, Microcorruption, OverTheWire, Flare-On archive, CTFtime write-ups,
Malware Traffic Analysis exercises, MalwareBazaar (handle with care).

**Reference**: ELF specification, Microsoft PE format docs, Apple's Mach-O reference, Intel SDM Vol. 2,
System V ABI, MITRE ATT&CK, OpenAPI 3.1 specification, SARIF 2.1.0.
