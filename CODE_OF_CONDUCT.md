# Code of Conduct

We follow the spirit of the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good faith, critique code rather than people, and keep discussions
about security research responsible. Harassment, discrimination and doxxing are not tolerated.

Report concerns privately to the maintainers via GitHub (Security tab or a direct message to a maintainer).
Maintainers may edit or remove contributions that violate these norms.
